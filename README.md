# CipherX — Kişisel Site

Selam! Bu site tamamen el yapımı **HTML + CSS + JS**. Framework yok, build yok, sihir yok.
Tarayıcıda aç, çalışır. O kadar.

## Nasıl açarım?
- `index.html` dosyasına çift tıkla → tarayıcıda açılır. Hepsi bu.

## GitHub Pages'e nasıl koyarım?
1. Bu dosyaları (`index.html`, `style.css`, `script.js`, `profil.png`) `cipherx404.github.io` deposuna at.
2. Değişiklikleri push'la.
3. Birkaç dakika içinde https://cipherx404.github.io yayında olur.

## profil.png nasıl değiştiririm?
- Kendi fotoğrafını `profil.png` adıyla bu klasöre koy, eskisinin üzerine yaz.
- Kare (örn. 512x512) olursa en güzel görünür.
- `profil.png` yoksa site otomatik olarak GitHub avatarını gösterir, yani kırık görüntü derdi yok.

## Ne nerede?
| Dosya | Ne işe yarar |
|---|---|
| `index.html` | Tüm içerik. Yazıları buradan değiştir. |

| `profil.png` | Profil fotoğrafı. Kendi fotoğrafınla değiştir. |
